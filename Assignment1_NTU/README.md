## Folder Structure & Setup

For any question that references a specific malware, binary, or file, you can find its corresponding sample in the `samples/` directory. These samples are provided for you to perform live analysis and testing on the actual binaries.

Please be careful when handling malware samples. Although all of them are older samples (> 7 years old) and are no longer used in modern campaigns, it is recommended that all testing be carried out inside a virtual machine (VM). Preferably, use a **Linux-based VM**, the teaching team highly recommends [**REMnux**](https://remnux.org/) or [**Kali Linux**](https://www.kali.org/) for this purpose.

To run virtual machines, you may use [**VMware Workstation Pro**](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion) if you are on Windows or Linux. For macOS users, [**VirtualBox**](https://www.virtualbox.org/wiki/Downloads) is a suitable alternative.
